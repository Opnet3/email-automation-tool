# Email Automation Tool

This Python script automates email filtering to identify important messages such as job opportunities, alerts, and notifications.

##  Features
- Connects to Gmail using IMAP
- Filters emails based on keywords
- Identifies important messages quickly
- Helps job seekers avoid missing opportunities

##  Use Case
This tool is useful for:
- Job seekers tracking opportunities
- People overwhelmed with emails
- Anyone who wants to automate inbox organization

##  Setup

1. Enable App Passwords on your Gmail account
2. Install Python (3.x)
3. Run the script:

```bash
python email_filter.py
